## Description

`Unconstrained Delegation` is a privilege that can be granted to User Accounts or Computer Accounts in an Active Directory environment, allowing a service to authenticate to another resource on behalf of `any` user.

![IIS Properties window showing delegation settings. "Trust this computer for delegation to any service (Kerberos only)" is selected. No services listed.](https://academy.hackthebox.com/storage/modules/233/image49.png)

---
## Kerberos Authentication With Unconstrained Delegation

When Unconstrained Delegation is enabled, the main difference in Kerberos Authentication is that when a user requests a TGS ticket for a remote service, the Domain Controller will embed the user's TGT into the service ticket.

When the service needs to authenticate to another service on behalf of the user, it will present the user's TGT ticket, which the service received with the TGS ticket.

![](../../Image/Pasted%20image%2020250928204438.png)

```ad-note
- Vấn đề Server with Unconstrained Delegation là ta bắt buộc phải trình cả TGS + TGT để kết nối tới. Điều này khiến lộ TGT nếu Server bị xâm nhập trước đó.
- Attacker cũng có thể thực hiện coercing máy nạn nhân kết nối tới Server bị xâm nhập nếu dùng PrinterBug.
- Khác với Constrained Delegation - Service Account là service account được gắn domain user và service trước. Tức là attacker chủ động dùng service account để mạo danh, trong khi server bị động chờ kết nối tới để lấy user's TGT.
```

## Attack Steps

- The attacker identifies systems on which Unconstrained Delegation is enabled for service accounts.

![](../../Image/Pasted%20image%2020250928194558.png)

- The attacker gains access to a system with Unconstrained Delegation enabled.
- The attacker extracts Ticket Granting Ticket (TGT) tickets from the memory of the compromised system using tools such as `Mimikatz`.

---
## Unconstrained Delegation Attack Detection

PowerShell commands and LDAP search filters used for Unconstrained Delegation discovery can be detected by monitoring PowerShell script block logging (`Event ID 4104`) and LDAP request logging.

The main goal of an Unconstrained Delegation attack is to retrieve and reuse TGT tickets, so Pass-the-Ticket detection can be used as well.

## Detecting Unconstrained Delegation Attacks With Splunk

Now let's explore how we can identify Unconstrained Delegation attacks, using Splunk.

**Timeframe**: `earliest=1690544538 latest=1690544540`

```shell
index=main earliest=1690544538 latest=1690544540 source="WinEventLog:Microsoft-Windows-PowerShell/Operational" EventCode=4104 Message="*TrustedForDelegation*" OR Message="*userAccountControl:1.2.840.113556.1.4.803:=524288*" 
| table _time, ComputerName, EventCode, Message
```
