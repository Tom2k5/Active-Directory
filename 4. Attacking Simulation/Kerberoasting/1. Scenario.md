### Create SPNs (Service Principal Name)

**Tạo tài khoản domain user mới:**
```
New-ADUser -Name "Service Account Tom SQL"
           -SamAccountName svc_sql
           -UserPrincipalName svc_sql@actvn.local
           -Enabled $true
           -PasswordNeverExpires $true
           -AccountPassword (ConvertTo-SecureString "123456a@1" -AsPlainText -Force)
```
- **`New-ADUser`**: cmdlet của PowerShell (yêu cầu module ActiveDirectory) để tạo user trong Active Directory.
- **`-Name "Service Account SQL"`**: tên đầy đủ (hiển thị trong ADUC).
- **`-SamAccountName svc_sql`: đây là logon name dạng cũ (pre-Windows 2000)**, tức username khi đăng nhập.
- **`-Enabled $true`**: tạo user ở trạng thái **đã bật** (active).
- **`-AccountPassword (Read-Host -AsSecureString "AccountPassword")`**: khi chạy, PowerShell sẽ hỏi bạn nhập mật khẩu → nó được đọc vào dưới dạng SecureString để dùng làm password cho tài khoản này.

**Đăng ký SPN và ánh xạ nó vào user mới:**
```
setspn -S MSSQLSvc/actvn.local:1433 svc_sql
```
- `MSSQLSvc` → service class của SQL
- `actvn.local` → hostname thật của server
- `:1433` → port SQL mặc định (nếu bạn dùng port khác thì đổi)
- `svc_sql` → account vừa tạo

Tương tự tạo các user và SPN khác:

### Defense Evasion

- Disable real-time protection: `Set-MpPreference -DisableRealtimeMonitoring $true`
- Disable the scanning of network files: `Set-MpPreference -DisableScanningNetworkFiles $true`
- Disable the blocking of files at first sight: `Set-MpPreference -DisableBlockAtFirstSeen $true`
- Disable Windows Defender AntiSpyware: `reg add "HKLM\SOFTWARE\Policies\Microsoft\Windows Defender" /v DisableAntiSpyware /t REG_DWORD /d 1 /f`

- On MS01:
```
Start-Process powershell -Verb runAs
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Unrestricted
```
